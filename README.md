This is a very simple 2d game make by using Html, CSS and JS. 
This is a simple platform game to learn the basic of the web game development.
I have also used animations.
We can play the game by using arrow keys Or W A S D keys to move the player and get powers to reach the diamond and we have to find a secret path to collect the diamond.
It has only one level and in future there will be more lavels.
